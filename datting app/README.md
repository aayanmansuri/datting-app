# ❤️ DilSe - Full-Stack Real-Time Dating Application

**DilSe** is a full-stack real-time dating web application built with React, Node.js, Express, Socket.IO, and SQLite.

## 🚀 Features
- **Real-Time 1-on-1 Private Chat:** Isolated chat rooms using Socket.IO.
- **AI Chat Companion (Priya Sharma):** Automated responses with realistic typing delays.
- **AI Wingman & Discover:** Modern dark-themed UI with match percentage and active status.
- **Persistent Chat History:** Messages stored in SQLite.

## 🛠️ Tech Stack
- **Frontend:** React.js, Vite, Tailwind CSS, Socket.IO Client
- **Backend:** Node.js, Express.js, Socket.IO, SQLite3
